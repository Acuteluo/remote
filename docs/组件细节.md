# 组件细节

> 主文档见 [../README.md](../README.md)。

## 组件与职责

| 组件 | 位置 | 作用 |
|---|---|---|
| meow-console | `console/server.py` + systemd 用户服务 | 门户本体: 状态面板 / Web 终端 / 远程桌面桥接 / 剪贴板 / 摄像头 / 电源 |
| meow-vnc | systemd 用户服务(x11vnc) | 只监听回环的 VNC 服务端, 由门户桥接给浏览器, **端口永不对外** |
| meow-forward | `lan_forward.py` + systemd 用户服务 | 把发往本机各网卡 IP(含 Tailscale 100.x)的端口镜像到回环 |

常用命令:

    systemctl --user status meow-console meow-vnc meow-forward
    journalctl --user -u meow-console -f
    tailscale status                     # 查看 Tailscale 设备

## 端口

默认 8390(控制台) / 5900(x11vnc), **都不是写死的**:

- 优先级: 命令行 `--port` > 环境变量 `MEOW_PORT` > `console/data/config.json` 里的 `port`
- VNC 端口同理: `--vnc-port` > `MEOW_VNC_PORT` > `config.json` 的 `vncPort`
- 换端口后 `lan_forward.py` 会自动跟着走(它读同一份 config)

## 运行时文件(全在 console/data/)

| 文件 | 内容 |
|---|---|
| `auth.json` | 登录凭据: 随机盐 + sha256(盐+密码), **不存明文** |
| `.secret` | 会话令牌的 HMAC 签名密钥 |
| `config.json` | 全部配置(输入方式 / 音量 / 端口 / 按窗口记忆的投递方式) |
| `audit.log` | 登录、终端、远程桌面、电源、配置的审计流水 |

备份 = 拷走这个目录; 重置 = 删掉它(下次启动会重新引导设置账号密码)。
