## 本轮修复

| 范围 | 原问题 | 修复后的行为 |

| 输入超时 | 返回超时的排队任务仍会在以后执行；粘贴结果不明时又逐字重发 | 尚未执行的任务取消；结果未知时不自动重发；队列容量原子限制为20 |
| 剪贴板 | 过期还原任务可能覆盖新内容；空选区未还原；手动写入可能被旧定时器覆盖 | 用世代号跳过旧还原，空选区也还原，显式操作取消自动还原 |
| 手机文本差分 | emoji按UTF-16两个码元计算删除次数 | 按Unicode码点计算，单个emoji只补一次退格 |
| 图传监测 | 20秒才有一次通道心跳结果 | 每5秒检测一次；保留多个待确认ping，使迟到pong仍能测量 |
| 终端/首页 | 旧连接关闭回调触发重复重连、覆盖新连接引用 | 回调校验连接身份，重连计时器可清理 |
| 终端后端 | 启动失败泄漏PTY；不合法尺寸消息使会话异常退出；preexec_fn在多线程fork后执行Python | 明确报错并清理PTY；无效消息跳过；独立子进程初始化控制终端，关闭后回收reader和shell |
| 配置 | 并发保存丢掉其他字段，读取可能碰到半写JSON | 读改写加锁，并原子替换文件；窗口投递方式记忆也在锁内合并 |
| 首次设置/HTTP | 并发设置可覆盖账号；负长度或超大请求体可阻塞；JSON列表使接口抛异常 | 首次设置互斥；拒绝非法/超限/不完整请求；要求JSON对象并返回错误 |
| 缓存 | 同秒等长修改仍使用旧ETag/URL版本 | 使用纳秒修改时间标识 |
| 主题/背景 | 慢响应覆盖新选择，上传图片内容与MIME可能来自不同文件 | 初始响应只在未交互时应用；上传使用文件快照，保留新选择 |
